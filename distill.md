# Knowledge Distillation from DeepSeek-V4-Pro

## Context

The project trains Chinese educational QA models (Qwen2.5) on the Fineweb-Edu-Chinese-V2.2 dataset using QLoRA. The existing `output` fields in the training data were generated by a smaller model. By distilling responses from DeepSeek-V4-Pro (a much stronger teacher model), we can generate higher-quality training targets that improve the student model's performance.

**Approach:** Response-level distillation (offline) — call the DeepSeek API to generate teacher responses for each training example, then train the student on those responses using the existing SFT pipeline. No changes to the loss function or training loop needed.

**DeepSeek API:** OpenAI-compatible at `https://api.deepseek.com`, models `deepseek-v4-pro` (stronger) and `deepseek-v4-flash` (cheaper). Supports thinking mode that returns chain-of-thought reasoning in a separate `reasoning_content` field. Dynamic concurrency-based rate limiting (no published RPM/TPM). Pricing: v4-pro at $0.435/1M input tokens (cache miss), $0.87/1M output tokens (75% discount until 2026/05/31).

## Implementation Details

### 1. Config — `configs/config.yaml`

```yaml
# Knowledge Distillation Configuration
distill:
  enabled: false                      # true = run distillation stage in pipeline
  api_base_url: "https://api.deepseek.com"
  api_key_env: "DEEPSEEK_API_KEY"     # env var name holding the API key
  model: "deepseek-v4-pro"            # "deepseek-v4-pro" or "deepseek-v4-flash"
  thinking_mode: true                 # capture reasoning_content from teacher
  reasoning_effort: "high"            # "high" or "max"

  raw_data_dir: "data/raw"
  distilled_data_path: "data/processed/distilled_data.jsonl"
  checkpoint_path: "data/processed/distill_checkpoint.json"

  max_concurrent: 5                   # semaphore limit for parallel API calls
  max_retries: 5                      # retries per request on 429/5xx
  base_backoff: 1.0                   # initial backoff seconds (doubles each retry)
  max_backoff: 60.0                   # backoff cap
  request_timeout: 120                # per-request timeout in seconds

  sample_size: 0                      # 0 = all data; >0 = random sample
  seed: 42
  cost_log_path: "data/processed/distill_cost.json"

dataset:
  use_distilled_data: false           # true = use distilled_output in training
```

### 2. Distillation Script — `distill.py`

Standalone async script. Reads raw data from `data/raw/*.jsonl`, calls DeepSeek API, writes `distilled_data.jsonl`.

**Key Functions:**

- `build_teacher_prompt(entry)` — constructs chat messages for the API. System message in Chinese establishes the teacher as an educational QA expert. User message includes `raw_content` as reference context, `instruction` as the question, and `input` if non-empty.

- `async call_deepseek_api(session, messages, config, semaphore)` — single API call with exponential backoff on 429/5xx. Returns `{content, reasoning_content, usage, error}`. In thinking mode, includes `reasoning_effort` in request body; omits temperature/top_p (DeepSeek ignores them in thinking mode).

- `load_raw_data(raw_data_dir, sample_size, seed)` — reads all `*.jsonl` from raw dir, optionally samples.

- `load_checkpoint(path)` / `save_checkpoint(path, data)` — JSON checkpoint mapping `{line_index: result}` for resumable processing. Atomic write via temp file + rename.

- `estimate_cost(entries, model)` — rough cost estimate using `len(text)/1.5` as Chinese char-to-token ratio.

- `async run_distillation(config)` — main loop: load data → load checkpoint → filter completed → batch process with `asyncio.gather` + semaphore → save checkpoint after each batch → write final output.

- `save_distilled_data(entries, checkpoint, output_path)` — merges raw entries with checkpoint results into `distilled_data.jsonl`.

**Teacher Prompt Design:**

```
System: 你是一位专业的中国教育问答助手。请根据提供的参考资料，生成高质量、准确、详细的教育问答回答。
要求：
1. 回答必须基于参考资料中的事实信息
2. 使用清晰的中文，适当使用markdown格式
3. 包含关键知识点的解释和扩展
4. 如果参考资料是外文，请准确翻译并整合信息
5. 回答应具有教育价值，适合学生学习使用

User: 参考资料：
{raw_content}

问题：{instruction}

{附加输入：input（如果不是空的）}

请生成一个高质量的教育回答：
```

**Output Format — `distilled_data.jsonl`:**

```json
{
  "instruction": "...",
  "input": "...",
  "output": "...",
  "raw_content": "...",
  "distilled_output": "...",
  "distilled_reasoning": "..."
}
```

Original `output` preserved as fallback. `distilled_reasoning` is empty string if thinking mode off.

**Checkpoint Format:**

```json
{
  "metadata": {
    "model": "deepseek-v4-pro",
    "total_entries": 1437066,
    "completed_entries": 5230,
    "failed_entries": 3
  },
  "entries": {
    "0": {"distilled_output": "...", "distilled_reasoning": "...", "usage": {...}, "error": null},
    "1": {"distilled_output": "", "distilled_reasoning": "", "usage": null, "error": "timeout"}
  }
}
```

**Error Handling:**

- Individual failures don't abort the run — failed entries get empty `distilled_output` with error logged
- API key missing → `ValueError` at startup
- 429 → exponential backoff with jitter, respect `Retry-After` header
- 5xx/timeout → retry up to `max_retries`
- At end: print failure summary; entries with errors fall back to original `output` during training

### 3. Data Preprocessing — `data_preprocess.py`

When `use_distilled_data: true` and the distilled data file exists, loads from it instead of `sft_data.jsonl`:

```python
use_distilled = dataset_config.get("use_distilled_data", False)
distilled_path = config.get("distill", {}).get("distilled_data_path", "")

if use_distilled and distilled_path and os.path.exists(distilled_path):
    print(f"Using distilled data from: {distilled_path}")
    source_path = distilled_path
else:
    source_path = sft_data_path
```

### 4. Training — `sft_train.py`

In `formatting_prompts_func`, selects output field based on config:

```python
use_distilled = dataset_config.get("use_distilled_data", False)

def formatting_prompts_func(example):
    instruction = example['instruction']
    input_text = example['input']
    if use_distilled and example.get('distilled_output'):
        output_text = example['distilled_output']
    else:
        output_text = example['output']
    # ... rest unchanged (context handling etc.)
```

## Usage

```bash
# Set API key
set DEEPSEEK_API_KEY=sk-...

# Run distillation standalone (with cost confirmation)
python distill.py --config configs/config.yaml

# Run distillation standalone (skip confirmation)
python distill.py --config configs/config.yaml --yes

# Run full pipeline with distillation enabled
# (set distill.enabled: true and dataset.use_distilled_data: true in config)
python main.py --config configs/config.yaml

# Train on distilled data (after distillation completes)
# (set dataset.use_distilled_data: true in config)
python sft_train.py --config configs/config.yaml --timestamp "20260514120000"
```
